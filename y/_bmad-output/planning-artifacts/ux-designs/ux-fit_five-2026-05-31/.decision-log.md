## Decisions Captured

1. UX artifacts are split into `DESIGN.md` and `EXPERIENCE.md`.
2. Mobile app is native phone-first for iOS and Android.
3. Bottom navigation uses Accueil, Joueurs, Match, Vestiaire, Profil.
4. The weekly match loop is the primary UX spine.
5. Reference app screenshots inform the direction but do not override the PRD.
6. Visual direction is dark matchday, turf green actions, whistle yellow prompts, kit red absence/errors, and Panini gold identity moments.
7. Team generator is treated as the hero interaction.
8. Vestiaire remains a fun/social layer, not the primary MVP product.
9. Pronostics stays deferred/hidden for MVP.
10. Rating and team-generation blocked states must explain next action.
11. Card generation is an earned post-OVR moment.
12. Push notification permission is requested after group/match relevance, not on first app launch.
13. First visual mockups cover Accueil/Match, Team Generator, Initial Rating, and Card/Share because these carry the MVP's core value and main UX risks.
14. Mockups are offline HTML references so they can be opened, reviewed, and iterated without committing to a frontend/native implementation stack yet.
